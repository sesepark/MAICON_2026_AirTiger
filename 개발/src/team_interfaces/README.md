# team_interfaces

팀 공통 `.msg/.srv/.action` 정의의 원본이다. 이 패키지는 자료형 정의만 관리하며 실행 노드는 없다. 초기 작성 시점(2026-11-15)에는 ROS 2 빌드·로봇 검증을 하지 않았다.

- 작업 전 [공통 규칙](../../AGENTS.md)과 [통신 계약](../../../노드_관리/interfaces.yaml)을 읽는다.
- 자료형 구조는 이곳에서 정의한다. YAML에는 타입·정의 경로와 필드 의미·단위·연결·정책을 기록한다.
- 변경 전 사용자 승인을 받고 사용 중인 모든 발행·구독·호출·제공 노드를 확인한다. 이미 승인된 범위는 재확인하지 않는다.
- 변경 후 관련 코드·YAML·changes를 함께 갱신하고 HTML의 실제 정의 파일 표시를 확인한다.
- 외부 표준·대회 제공 타입을 이 패키지에 복제하거나 미공개 필드를 추정해 만들지 않는다.
- 새 정의 파일 추가 시 CMakeLists.txt의 생성 목록과 package.xml 의존성을 갱신한다.
