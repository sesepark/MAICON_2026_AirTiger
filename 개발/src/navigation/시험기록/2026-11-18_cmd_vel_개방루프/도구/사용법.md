# cmd_vel 웹 조종 (시험)

웹 버튼으로 `/cmd_vel`을 잠깐 내보내 로봇을 조금 움직이고, 그동안 `/odom`이 얼마나 변했는지 표로 보여 준다. 정식 navigation 코드가 아니며 새 노드·토픽을 정의하지 않는다.

## 실행

1. 팀 지정 와이파이에 연결한 PC에서(접속 정보는 `공식_자료/로봇_접속정보.md`, 커밋 금지) `scp teleop_server.py team@<UGV IP>:/home/jetson/team/tmp_teleop.py`
2. `ssh team@<UGV IP>` 후 `sudo ugv-shell`
3. 컨테이너 셸에서 `python3 /home/ws/team/tmp_teleop.py`
4. PC 브라우저에서 `http://<UGV IP>:8790` (8765는 `~/team`의 `UGV_Sensor_Server.py`가 사용 중이라 피했다)

## 로그

서버를 켤 때마다 새 파일 `teleop_<날짜_시각>.jsonl`이 만들어지고, 한 줄에 JSON 하나씩 즉시 기록된다. 로봇 쪽 위치는 `/home/jetson/team/tmp_teleop_logs/`(컨테이너에서는 `/home/ws/team/tmp_teleop_logs/`).

| `ev` | 내용 |
|---|---|
| `server_start` / `server_stop` / `server_error` | 시작(포트·상한·pid), 종료, 예외 |
| `http` | 모든 POST 요청(경로·접속한 IP·본문) |
| `move_start` / `move_end` | 명령값·종류·방식·목표, 시작 odom, 매치 상태 / 발행 횟수, 구동 시간, odom 결과, 끝 odom |
| `measured` | 사용자가 입력한 실측 값과 목표·odom 대비 오차 |
| `cmd` | 발행한 `/cmd_vel` 한 번마다(속도·경과 시간) |
| `odom` | 이동 중과 정지 후 0.6 s 동안의 `/odom` 샘플 전부(위치·방향·속도·stamp) |
| `cmd_zero` | 0 속도를 보낸 이유(`end_of_move`, `abort`, `stop_button`, `exception`, `server_exit`) |
| `move_rejected` / `bad_request` / `move_error` | 거절·잘못된 요청·예외(트레이스백) |
| `match_state` | `/mil/match_state`가 바뀔 때 |

PC로 가져오기: `scp team@<UGV IP>:/home/jetson/team/tmp_teleop_logs/*.jsonl .`

## 오차 측정 방법

1. 바닥에 출발선을 표시하고 로봇 앞쪽을 비운다. 방식(시간 기준 / odom 기준)과 속도를 고른다.
2. 정해진 거리·각도 버튼(전진 0.5·1m, 후진, 좌·우 90°·180°·360° 또는 직접 입력)을 한 번 누른다.
3. 멈춘 뒤 줄자로 잰 이동 거리(m) 또는 각도(°)를 결과 표의 **실측** 칸에 입력하고 Enter. 크기만 입력한다.
4. 표에 `실측−목표`(명령이 얼마나 빗나갔나)와 `odom−실측`(odom이 얼마나 틀렸나)이 계산되고, 입력값과 오차는 로그의 `measured` 줄에도 남는다.
5. 같은 명령을 5번 이상 반복해 흩어짐을 본다. 속도도 바꿔 가며 반복한다.

- 시간 기준: `목표 / 속도` 초 동안 일정 속도로 발행한다. 명령 대비 실제 이동(개방 루프)을 잰다.
- odom 기준: `/odom`이 목표에 닿으면 멈춘다. 닿지 못하면 시간 상한에서 멈춘다. 정지 후 미끄러짐을 잰다. 이때 `odom−실측`이 odom의 신뢰도를 보여 준다.
- 상한: 거리 1.5m, 회전 360°, 속도 0.2m/s·0.8rad/s, 한 번 이동 20초.

## 안전

- 한 번 누르면 설정한 속도·시간만큼만 움직인다(속도 상한 0.2 m/s·0.8 rad/s, 시간 상한 2 s). 이동은 한 번에 하나.
- STOP 또는 스페이스바는 즉시 정지. 서버가 죽거나 연결이 끊기면 브리지의 `cmd_vel_timeout`(0.5 s)으로 자동 정지한다.
- 매치 모드에서는 쓰지 않는다. 경기 중 `mil_match_node`가 손으로 띄운 팀 스크립트를 정지시킨다.
- 인증이 없다. 같은 와이파이의 누구나 접속할 수 있으니 시험하는 동안만 켠다.

## 정리

시험이 끝나면 로그를 PC로 가져온 뒤 Ctrl+C로 서버를 끄고, 로봇의 `/home/jetson/team/tmp_teleop.py`를 지운다. 로그 폴더는 지우기 전에 반드시 가져온다. `team_node.py`는 건드리지 않는다.
