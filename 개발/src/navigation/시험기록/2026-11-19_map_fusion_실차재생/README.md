## 돌리는 법

ROS 없이 돈다 (`bagread.py` 가 bag 의 CDR 을 직접 푼다). 로봇을 움직이지 않는다.

```bash
cd 개발/src/navigation/시험기록/2026-11-19_map_fusion_실차재생
python -I replay.py <받을_폴더>/1118_202820/bag/bag_0.db3 on.json  true     # 지도 고치기 켬 (약 1분)
python -I replay.py <받을_폴더>/1118_202820/bag/bag_0.db3 off.json false    # 끔
python -I report.py off.json on.json
# 예전 커밋과 견주기: git archive <커밋> 개발/src | tar -x -C <폴더>  →  replay.py … true <폴더>/개발/src/navigation
```

재생이 맞는지: `1118_202820` 을 지도 고치기 없이 다시 돌린 위치가 그때 로봇이 낸 위치와 중앙값 0.0 cm · p95 0.5 cm · 최대 7.0 cm 로 같다 (5678개).
`1118_201710` 은 그때 로봇의 코드가 지금과 달라 실차와 견줄 수 없다 (끈 것과 켠 것끼리만 견준다).

읽는 법:

- `1118_202820` 에서 「튄 위치」 가 `38920da` 보다 많은 것은 정합에 더한 상자가 늦게 · 적게 생겨서다. 판 조각이 13 ~ 25 cm 폭으로만 보여 「30 cm 넘는 폭」 조건에 걸렸다 — 40 cm 상자가 아닌 것을 넣지 않으려는 조건이 뜻한 대로 든 것이고, 끈 것(46)보다는 낫다.

- 가상 시험: `38920da` 를 main 에 그대로 합치면 107개 중 1개 실패(`test_team_test_replay` 의 「입구로 나오는 다른 UGV」 — 서 있는 UGV 가 상자로 들어가 닿음 27번). 고친 뒤 116개 모두 통과.

## 고정 기둥(aaf5a44)을 넣은 뒤 — 올린 코드로 다시 돌린 것

위 표는 고정 기둥이 main 에 들어오기 전의 숫자다 (`fixed_pillars=false` 로 돌리면 올린 코드도 같은 숫자가 나온다).
모의 경기장은 6.0 × 4.8 m 라 기둥의 기본 배치가 켜지는데, **그 자리에 실제 기둥이 없다** (로봇이 기둥 자리 (5.8, 1.6) 안을 지나다녔다).

| `1118_202820`, 기둥 켬(기본) | 끔 | 켬 — 기둥을 믿는 점으로 셈 (`953e07f`) | **켬 — 기둥은 믿는 점에서 뺌** |
|---|---|---|---|
| 5 cm 넘게 튄 위치 | 35 | 133 | 36 |
| 지도 고치기 관측 (고침 / 전체) | – | 2583 / 2803 | 1004 / 2803 |

기둥을 「자세가 맞다는 근거」 로 세면, 기둥이 가정한 자리에 없을 때 틀린 자세로도 지도를 고친다. 그래서 기둥은 정합 · 설명되는 점 · 「새 상자 후보 아님」 에만 쓰고
믿는 점(외벽 + 확인한 상자)에는 넣지 않는다. 실제 경기장에는 기둥(노랑 · 검정 줄무늬 블록)이 고정돼 있어 정합에는 그대로 도움이 된다.

```bash
python -I replay.py <bag_0.db3> 결과.json true fixed_pillars=false     # 이름=값 으로 SLAM 노드 파라미터를 바꿔 돌린다
```

## 검토하며 바로잡은 것

처음 검토(고치기 전) 때 적은 것 가운데 기록으로 다시 보니 틀린 것:

- 「벽에 붙은 상자는 확인이 안 된다 (벽 위의 점을 맞은 점에서 빼서)」 → 이 기록에서 그 규칙의 영향은 0 이었다 (상자 12개 모두 벽 점을 넣어 세나 빼고 세나 같음). 확인 · 고치기가 막힌 까닭은 안전장치의 「외벽 점 10개」 였다.
- 「(3.5, 2.1) 은 면에 점이 맞는데도 잘못 뺐다」 → 맞은 관측과 광선이 지나간 관측은 서로 다른 때였고(같은 때는 2802번 중 3번), 뺀 것이 맞다. 다만 「지나가면 맞은 점이 있어도 깎는다」 는 코드의 문제는 가상 시험으로 확인된다 (20 cm 어긋난 진짜 상자가 빠짐 → 고친 뒤 유지).

## 파일

| 파일 | 내용 |
|---|---|
| `bagread.py` | ROS 2 sqlite bag 읽기 (LaserScan · Odometry · Imu · Float32MultiArray · FieldMap · ServerState · PoseStamped · String · Twist) |

| `report.py` | 결과 json 여러 개를 나란히 |
