연습 경기 다섯 판(10:35 · 10:50 · 11:19 · 11:47 · 14:12)의 `navigation/debug.jsonl` 0.5 s 위치로 잰 서서 돌기:

| 명령 (rad/s) | 표본 | 실제 중앙값 (rad/s) | 0.1 rad/s 도 못 돎 |
|---|---|---|---|

멈춘 뒤 더 돈 각도는 중앙 −1° · 최대 10° (128번). 주행 중 1.5 ~ 2.0 rad/s 는 0.55 ~ 0.87 rad/s.
→ `시험기록/web_drive/sim_world.REAL_ROBOT_1119` (서서 돌 때 1.4 rad/s 밑은 안 돎 · 각속도 명령의 0.35 배). 기존 `REAL_ROBOT`(명령만큼 돎)은 그대로 둔다.

```bash
python -X utf8 rot_bench.py <navigation 패키지> <A|B> [seed ...]   # A = REAL_ROBOT, B = REAL_ROBOT_1119
```

## 서서 돌기를 실제 회전에 맞춰 올리기 (2026-11-19 밤, `spin_max_w`)

환경변수 `DRIVE_SET="이름=값,이름=값"` 으로 주행 파라미터를 바꿔 돌릴 수 있다 (예: `DRIVE_SET="rotate_max_w=1.6,rotate_kick_w=0,spin_max_w=2.4" python -X utf8 rot_bench.py <패키지> B 1 2 3`).

아래는 **`rotate_max_w` 가 1.6 이던 코드(a4ed85a 위)** 에서 잰 것이다. 같은 날 밤 `rotate_max_w` 1.6 → 2.2 · `rotate_kick_w` 2.8 이 따로 들어왔고(fba503f),
그 위에서는 다시 재지 않았다. 모델 B · seed 1 ~ 8 (목표 256개):

| | 도착 | 방향 10° 안 | 걸린 시간 | 방향 맞추기 | 서서 돌기 | 닿은 주기 |
|---|---|---|---|---|---|---|
| 끔 | 256 | 190 | 2420 s | 846 s | 548 s | 311 |
| 켬 (`spin_max_w` 2.4) | 247 | 180 | 2251 s | 710 s | 516 s | 377 |

켜면 시간은 줄지만 상자 면 0.19 ~ 0.22 m 곁 자리에서 「돌 자리 없음」 이 는다 (도착하는 자세가 몇 cm 달라진다). 이 모델의 「1.4 위는 명령의 0.35 배」 는
1.6 rad/s 까지만 실측이다 — 그 위는 가정. 그래서 기본은 끔(`spin_max_w` 0)이고, 꺼 둔 동안에도 `debug.jsonl` 의 `state.turn` 에 실제 빠르기(`rate`) · 낸 명령(`cmd`) ·
잰 방법(`src`) · IMU 확인(`gyro_ok` / `gyro_bad` / `gyro_ratio`)을 남긴다.
